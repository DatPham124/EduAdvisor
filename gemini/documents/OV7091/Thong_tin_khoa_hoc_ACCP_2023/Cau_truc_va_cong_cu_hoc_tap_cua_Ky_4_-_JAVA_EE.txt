Cấu trúc và công cụ học tập của Kỳ 4 - JAVA EE:
Kỳ 4 tập trung vào JAVA EE, với tổng thời lượng 200 giờ, bao gồm 90 giờ lý thuyết, 110 giờ thực hành và 68 giờ tự học. Các học phần bao gồm: Giới thiệu về lập trình Dart (16 giờ), Phát triển ứng dụng bằng Flutter và Dart (40 giờ), Phát triển thành phần web bằng Jakarta EE (40 giờ), Xây dựng ứng dụng web Java với Spring Framework (24 giờ), Phát triển ứng dụng doanh nghiệp trong Jakarta EE (40 giờ), Tạo dịch vụ cho web (16 giờ), và Dự án phát triển ứng dụng doanh nghiệp Java (24 giờ). Các công cụ và phần mềm sử dụng là Flutter SDK 1.22 với Dart 2.10.x trở lên, Jakarta EE Platform 10, Spring 6.x, Spring Boot 3.0.x. Cơ hội nghề nghiệp sau kỳ này bao gồm Nhà phát triển Full-Stack, Nhà phát triển ứng dụng đa nền tảng, Nhà phát triển ứng dụng web và Nhà phát triển ứng dụng doanh nghiệp.
