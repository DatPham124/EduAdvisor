So sánh chương trình ACCP cũ và mới:
Chương trình ACCP mới (OV-7091) có những cập nhật đáng kể so với chương trình cũ (OV-7023). Cụ thể, về UI/UX cho thiết kế trang web, chương trình mới sử dụng Figma Toolkit, trong khi chương trình cũ không có. Về phát triển web Front-end, chương trình mới sử dụng React 18.x hoặc cao hơn, thay vì AngularJs và Angular 9 của chương trình cũ. Về Java, chương trình mới sử dụng Java Development Kit (JDK) 19.x, so với Java 15. Về Java EE, chương trình mới sử dụng Jakarta EE 10, Spring 6.x, Spring Boot 3.0.x, thay vì Java EE 8, Spring 5.1 hoặc cao hơn. Chương trình mới bổ sung NoSQL Database với MongoDB 6.0 hoặc cao hơn. Về .NET, chương trình mới sử dụng Microsoft Visual Studio 2022 Professional, so với Microsoft Visual Studio 2019 Professional. Chương trình mới cũng bổ sung Python với Python SDK 3.x. Cuối cùng, về Node.js, chương trình mới sử dụng NodeJS 18.x, so với NodeJS 13.x.
