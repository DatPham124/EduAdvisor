Cấu trúc và công cụ học tập của Kỳ 1 - Lập trình:
Kỳ 1 tập trung vào lập trình, với tổng thời lượng 220 giờ, bao gồm 102 giờ lý thuyết, 118 giờ thực hành và 68 giờ tự học. Các học phần bao gồm: Xây dựng logic và lập trình cơ bản (40 giờ), Xây dựng trang web hiện đại (40 giờ), UI/UX cho thiết kế web đáp ứng (16 giờ), Phát triển web Front-end với React (24 giờ), eProject-Phát triển web đáp ứng (20 giờ), Quản lý dữ liệu với SQL Server (32 giờ), và Phát triển PHP với Laravel Framework (48 giờ). Các công cụ và phần mềm sử dụng là NetBeans 8.1 trở lên, CoffeeCup Free HTML5 Editor hoặc Notepad++, Figma Toolkit, React 18.x trở lên, MS SQL Server 2019 Standard Edition, PHP 8.0 và Laravel FW. Cơ hội nghề nghiệp sau kỳ này bao gồm Nhà phát triển trang web đáp ứng và Nhà phát triển PHP.
