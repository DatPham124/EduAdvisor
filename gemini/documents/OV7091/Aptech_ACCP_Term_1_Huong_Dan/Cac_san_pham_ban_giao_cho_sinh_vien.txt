Các sản phẩm bàn giao cho sinh viên:
Các sản phẩm bàn giao cho sinh viên bao gồm một bộ tài liệu gồm 7 đầu sách cho ACCP Kỳ 1 OV-7091.
*   Xây dựng logic và Lập trình cơ bản: Mã sách OV-C0056, Tên sách Elementary Programming in C-INTL.
*   Xây dựng trang web hiện đại: Mã sách AINNFENDT10323E000, Tên sách FrontEnd Technologies for Beginners.
*   UI/UX cho thiết kế web đáp ứng: Mã sách AINNEUIUX10721E000, Tên sách Elegant and Effective Web Design with UI and UX.
*   Phát triển web Frontend với React: Mã sách AINNREACT10423E000, Tên sách Frontend Web Development with ReactJS.
*   eProject-Phát triển web đáp ứng: Mã sách AINNEPRWB10323E000, Tên sách ePG-Build Responsive NextGen Websites.
*   Quản lý dữ liệu với SQL Server: Mã sách AINNSQLSR10920E000, Tên sách Intelligent Data Management with SQL Server.
*   Phát triển PHP với Laravel Framework: Mã sách AINNPHPLV10821E000, Tên sách PHP Web Development with Laravel.
