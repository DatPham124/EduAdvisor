Tạo thư mục "input_pds" cùng cấp với file .py để chứa các file pdf
Nhớ tạo file .env để thêm biến môi trường chứa API vào (GEMINI_API_KEY)
Chạy file `requirements.txt` để cài đặt môi trường. File `requirements.txt` còn thiếu một số thư viện, cần được bổ sung

1. Thêm dữ liệu từ thư mục và tự động xóa dữ liệu được thêm xong ở folder /input_pdfs
2. Ghi nhớ lịch sử hội thoại

PROBLEM: Chạy lâu từ 10-30s, cần tối ưu
